# 🌿 Tulsi Mala eCommerce Website

A fast, secure, and modern eCommerce solution for selling Tulsi Mala and spiritual products with **smart customization, seamless checkout, Razorpay payments, and Firebase backend**.

---

## 🚀 Features & Complete Flow

### 🛒 Smart Shopping Experience

* Real-time product selection with instant price updates
* Advanced customization (bead size, length, thread color, pendant, etc.)
* Intelligent UI that adapts based on selected product
* Live product image preview
* Smooth, fast single-page checkout

---

### 👤 Seamless Order Flow

1. Select product & customization
2. Enter delivery details
3. Click **Pay & Place Order**
4. Secure order created in backend
5. Razorpay checkout opens
6. Complete payment
7. Payment verified securely
8. Order marked as **Paid**

---

### 💳 Secure Payment System

* Razorpay **order-based checkout integration**
* Auto payment capture enabled
* Signature verification using **HMAC SHA256**
* Backend-controlled validation (no frontend trust)
* Fraud-resistant, production-ready architecture

---

### 🔥 Backend & Database

* Firebase Realtime Database for storing orders
* Unique order ID generation & tracking
* Stores customer info, product details, customization, and payment data
* Real-time order status updates

---

### 📱 UI / UX Highlights

* Clean, modern, mobile-first design
* Fully responsive across all devices
* Smooth animations and intuitive flow
* Smart form validation with error highlighting
* Fast and frictionless checkout experience

---

### ⚠️ Validation & Reliability

* Required field validation
* 10-digit phone validation
* Payment failure handling
* Network error handling
* Safe retry flow without data loss

💡 Built for a smooth, secure, and scalable online shopping experience.
